🏋️ AI Gym Coach
A real-time AI workout coach that watches your form, counts reps, and gives voice feedback.

AI Gym Coach combines computer vision, pose estimation, and Generative AI to analyze exercises through a webcam and provide personalized coaching.

Highlights
Real-time pose and exercise analysis
Rep counting and form-error detection
Supports Squats, Push-ups, Biceps Curls, Shoulder Press, and Lunges
Groq LLM for coaching feedback
Groq Orpheus TTS for voice guidance
Workout history and user authentication
Built with a modular Python architecture

How It Works
Webcam → Pose Detection → Exercise Analysis
       → Form Issue → Groq LLM → Orpheus TTS → 🔊 Feedback

✨ Features
🎥 Real-time exercise detection using webcam
🦴 Pose landmark detection using MediaPipe
🏋️ Supports multiple exercises:
Squats
Push-ups
Biceps Curls
Shoulder Press
Lunges
📊 Real-time exercise metrics and repetition tracking

⚠️ Detects common form issues
🤖 AI-generated coaching feedback using Groq LLM
🔊 Voice feedback using Groq Orpheus TTS
📈 Workout progress and history tracking
🔐 User login functionality
🌐 Built with Streamlit and Streamlit-WebRTC
